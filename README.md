# 🐘 Desarrollo Web en Entorno Servidor: PHP

Repositorio dedicado a los apuntes, ejercicios prácticos y proyectos desarrollados en la asignatura de **Desarrollo Web en Entorno Servidor (DWES)** utilizando PHP.

---

## 📌 Contenidos del Curso

1. **Introducción a PHP y Sintaxis Básica**
   - Variables, tipos de datos y operadores.
   - Estructuras de control (condicionales y bucles).
   - Funciones personalizadas y embebido de PHP en HTML.

2. **Manejo de Formularios y Arrays**
   - Métodos `GET` y `POST`.
   - Validaciones, saneamiento y tratamiento de entradas.
   - Manipulación de arrays numéricos y asociativos.

3. **Gestión de Estado y Sesiones**
   - Trabajo con `$_COOKIE` y `$_SESSION`.
   - Control de acceso, autenticación de usuarios y roles.

4. **Programación Orientada a Objetos (POO)**
   - Clases, objetos, propiedades y métodos.
   - Herencia, interfaces, abstracción y namespaces.
   - Manejo de excepciones (`try / catch`).

5. **Acceso a Bases de Datos**
   - Conexión a bases de datos relacionales mediante **PDO** (PHP Data Objects).
   - Consultas preparadas para prevenir inyección SQL.
   - Operaciones CRUD completas (Create, Read, Update, Delete).

6. **Arquitectura Web yBuenas Prácticas**
   - Patron **MVC** (Modelo-Vista-Controlador).
   - Gestión de dependencias con **Composer**.
   - Integración con bases de datos no relacionales y APIs RESTful.

---

## 🛠️ Requisitos e Instalación

Para ejecutar este entorno localmente necesitas disponer de un servidor web con soporte para PHP y MySQL.

### Entorno Recomendado
- **PHP** >= 8.1
- **MySQL** / **MariaDB**
- **Servidor Web:** Apache, Nginx o solución empaquetada (XAMPP, Laragon, Docker).
